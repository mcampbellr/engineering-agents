# AI Audit Report Format Enforcer

> Validate the generated report against structural rules, fix issues in place, and export the final artifacts. Runs after report-generator.

---

Goal: Read `reports/ai_audit.md`, validate ALL structural checks, fix formatting
in place, then export MD + JSON + history.

## STOP-BEFORE-EXPORT CHECKS (rejection → re-run report-generator)
Reject and regenerate (step 9) if ANY fail:
1. Report contains exactly **16 numbered sections**.
2. Section 1 is "AI Audit Scoring Breakdown" with **8 scored lines + Overall Score + AI-Readiness Posture**.
3. Section 2 is "Executive Summary" containing the **Overall Score**.
4. Sections 3–10 each contain a "Score:" line as **[Score]/100 ([Label])**.
5. Sections 3–10 each contain a "Score Breakdown:" with **Base and Final** lines.
6. Sections 3–10 are **ordered by score ascending** (lowest first).
7. The 8 scores in Section 1 **match** their detail-section scores (3–10).
8. Overall Score in Section 1 **equals** Overall Score in Section 2 and equals the
   weighted formula result (recompute to verify; sum of area weights = 1.00).
9. Posture label matches the Overall Score range.
10. Section 13 (Legal & Compliance Advisory) leads with the "not legal advice" disclaimer.
If scores are missing entirely, re-run report-generator before exporting.

## FIX-IN-PLACE FORMATTING
- Headings `## X. Section Name` (number + period). H1 title first, nothing before it.
- Bullets `- `; numbered `1. `. Severity tags `[HIGH]`/`[MEDIUM]`/`[LOW]`.
- Scores `[Score]/100 ([Label])`, Label ∈ {Strong, Fair, Weak, Critical}.
- OWASP LLM ids present on Area-7 / Section-11 security findings where applicable.
- No leaked generator/rubric instructions, no "SCORING HINTS" text, no `<system-reminder>`.
- Every finding cites `file:line` (or explicit "Not found"). One blank line between sections.

## EXPORTS (mandatory)
1. Markdown → `reports/ai_audit.md` (validated).
2. JSON → `reports/ai_audit.json` (schema in report-generator.md; values must match the MD).
3. History → `reports/.history/last_ai_scores.json`.
Run: `mkdir -p reports/.history`

```

Skill: ai-audit
Date: [YYYY-MM-DD]
---
```
Resolve name/version from the nearest `.claude-plugin/plugin.json` up-tree, else
`ai-audit` / `unknown`.
